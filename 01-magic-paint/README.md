# Magic Paint 🎨

An interactive generative drawing experiment built with p5.js.

Mouse movement influences the brush size and color, while randomness adds variation to position, size and rotation. Moving the mouse faster increases the blue color channel, and holding the mouse activates an explosion effect.

## Controls

- **Mouse movement** → Paint
- **Hold mouse** → Explosion mode
- **1** → Rectangle
- **2** → Circle
- **3** → Triangle
- **T** → Trail on/off
- **C** → Clear canvas

## Concepts

- Mouse interaction
- `map()` and value mapping
- Randomness
- Transformations
- State and boolean toggles
- Keyboard interaction
- Functions and refactoring

## Built with

- p5.js
